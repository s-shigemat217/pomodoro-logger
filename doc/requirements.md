# 要件定義書：pomodoro-logger

## 1. 背景・課題・目的
* **背景:** プログラミング学習の継続や集中の維持には、適切な作業管理と記録が不可欠である。
* **課題:** ポモドーロタイマー、学習メモの記録、GitHubへのコミットが別々のツールに閉じており、管理の手間がかかる。
* **目的・方針:** ポモドーロタイマーでの作業完了と同時に学習メモを自動でGitHubへCommit & Pushし、学習データを可視化するWebアプリを構築することで、学習の自動記録とモチベーション向上を実現する。

---

## 2. システム概要
### 2.1 システムの概要・システム化の範囲（スコープ）
* **システム概要:** ポモドーロタイマー、GitHub API連携自動コミット機能、学習統計ダッシュボードを備えた個人学習者向けSPAツール。
* **対象範囲（MVP）:**
  * タイマー計測、タスクCRUD、GitHub API経由の自動コミット、学習ログのグラフ表示
* **対象外（将来拡張）:**
  * リアルタイム音声通知、複数ユーザー間でのSNS機能、チーム管理機能。

### 2.2 システム構成・使用技術
| 区分 | 技術スタック / サービス | 選定理由・目的 |
| :--- | :--- | :--- |
| **フロントエンド** | Angular | TypeScriptを用いたコンポーネント指向・状態管理の学習 |
| **バックエンド** | Python (FastAPI または Flask) | RESTful APIの構築、外部API（GitHub）との連携処理 |
| **データベース** | PostgreSQL (または SQLite) | リレーショナルデータの管理（タスク・作業ログ） |
| **外部連携** | GitHub REST / GraphQL API | 学習メモの自動Commit & Push |
| **インフラ** | Vercel / Render (または AWS S3+Lambda) | クラウド環境へのデプロイ |

## 3. 機能要件（要件・機能一覧）
### 3.1 優先度定義
* **Must:** サービス提供に必須な初期リリース機能（MVP）
* **Want:** 追加検討機能

### 3.2 機能一覧

| ID | 大項目 | 機能名 | 詳細・挙動 | 優先度 |
| :--- | :--- | :--- | :--- | :--- |
| F-01 | **ポモドーロ** | タイマー機能 | 25分作業 / 5分休憩のカウントダウン。開始・一時停止・リセット | **Must** |

## 4. 非機能要件・システム構成
### 4.1 UI / UX
* PCブラウザからの操作をメインとし、シンプルな操作感を重視する。
* ポモドーロタイマー動作中は集中を阻害しない画面レイアウトとする。

### 4.2 セキュリティ・認証
* GitHub Personal Access Token などの機密情報は、フロントエンドに露出させずバックエンドで安全に保持・利用する。
* 環境変数は `.env` ファイルで管理し、Gitリポジトリにはコミットしない。

### 4.3 運用・デプロイ
* GitHub Actions 等によるCI/CD（またはVercel/Renderの自動ビルド機能）を導入し、`main` ブランチへのマージで自動デプロイされる仕組みを作る。
